# RPG Maker 全能工具

把两个原本独立的 RPG Maker 工具合并成一个：

| 能力 | 做什么 |
| --- | --- |
| **文本翻译** | 扫描游戏内全部文本 → 批量机翻 → 生成汉化版（可注入中文字体） |
| **存档修改** | 读存档改金币 / 道具 / 角色 / 开关变量，也能改游戏数据表（价格、攻击力…） |

支持 **RPG Maker MV / MZ / VX Ace / VX / XP**；**2000/2003 只识别、不修改**。

---

## 一、怎么启动

### 方式 1：双击（推荐）

双击 **`启动.bat`**。它会自己找 Python、做一次自检、启动服务并打开浏览器。

### 方式 2：命令行

```powershell
cd <本目录>
python app.py                 # 启动并自动打开浏览器
python app.py --port 8765     # 指定端口
python app.py --no-browser    # 不自动开浏览器
python app.py --check         # 只自检并退出（退出码 0 = 通过）
python app.py --check --json  # 机器可读的自检报告
```

浏览器会打开 `http://127.0.0.1:8765`（端口被占用时会自动换）。
**关掉窗口（或按 Ctrl+C）即退出。**

### 环境要求

* **Python 3.8 或更高**（3.10 实测通过）
* **不需要 pip 安装任何东西** —— 整个工程只用标准库
* Windows 实测通过；macOS / Linux 未做验证（代码里没有平台专属依赖，
  只有"在文件管理器中打开目录"和"原生文件对话框"两处做了平台分支）

## 二、文本翻译怎么用

1. **选游戏目录** —— 填或点「浏览…」，指到含 `www` / `data` / `Data` 的那一层，
   点「打开并识别」。工具会显示识别到的引擎与数据目录。
2. **扫描文本** —— 勾选要提取的内容（注释 / 备注 / 事件名 / 动画名），
   点「扫描文本」。几万条文本会在后台跑，有进度条，可以随时取消。
3. **看列表、改译文** —— 支持搜索、按类别（对话 / 名称 / 描述…）与状态筛选。
   双击那一行的输入框改译文，回车即存；不想翻的条目点「跳过」。
   **进度会自动保存**，关掉工具再打开同一游戏可以接着做。
4. **设置翻译引擎** —— 四种可选：
   * **Google 翻译**：免费，不需要密钥
   * **OpenAI 兼容接口**：填 OpenAI / DeepSeek / Kimi / Qwen 等的地址与密钥
   * **本地 Ollama**：默认 `http://localhost:11434/v1`，完全离线
   * **DeepL**：需要 DeepL API Key

   填完点「接口自检」确认能通，再点「开始翻译」。
5. **生成汉化版** —— 两种方式：
   * **写副本（默认、推荐）**：复制到新目录（默认 `<游戏名>_汉化`），**原游戏不动**
   * **覆盖原游戏**：直接改原目录，**会先自动备份**，并把备份路径显示在界面上

   可选注入中文字体（MV/MZ 改写 `core.js`；VX Ace/XP 装进系统字体库并注入脚本）。
6. **还原** —— 「刷新备份列表」里可以一键还原任何一次备份。
   **还原之前还会自动再备份一次当前状态** —— 所以"还原错了"也能再还原回来。

### 关于隐私

出网请求**只包含剥离控制码后的纯文本**，不含文件名、路径、游戏目录。

## 三、存档修改怎么用

1. **读取游戏数据** —— 选游戏目录，点「读取游戏数据」。
2. **选存档** —— 列表里选一个点「载入」。
   如果发现**多个含存档的目录**（有些游戏有自动存档），界面会提醒你确认改的是哪一个。
3. **改数值** —— 改动先放在**内存**里，界面顶部会显示「有未保存的改动」：
   * **金币 / 步数 / 道具**：直接改数字，点「应用」
   * **角色**：等级 / 经验 / HP / MP / 属性加成 / 技能列表
   * **开关 / 变量**：开关勾选，变量填数字
   * **游戏数据表**：改价格 / 攻击力 / 初始等级等（这一项**作用于所有存档**）
4. **保存存档** —— 点「保存存档」并确认。写回前自动备份，
   保存后界面会显示**本次备份位置**。不想改了就点「放弃改动并重新载入」。
5. **还原** —— 和翻译一样，备份列表可一键还原，还原前再备份一次。

> **队伍成员只读**：这是原工具的既有行为（没有写回路径），本工程保持一致。

## 四、安全约定（这些是硬约束，不是建议）

| 约定 | 说明 |
| --- | --- |
| **默认零破坏** | 翻译默认只写副本；改存档默认只改内存，点保存才落盘 |
| **写前必备份** | 任何覆盖操作前先把将被修改的文件复制到游戏目录下的「汉化备份_*」 |
| **备份可还原** | 备份列表在界面上可点；还原前还会为当前状态再备份一次 |
| **覆盖要确认** | 覆盖原游戏 / 写回原存档 / 写回数据表 / 还原，都要先弹二次确认 |
| **原子写入** | 写文件用"临时文件 + 替换"，中途失败原文件一个字节都不变 |
| **未改内容原样保留** | 没动过的字段按字节保留（有 300 个真实存档样本的零漂移断言） |

## 五、开发者入口

> 想改代码 / 接手这个工程，先读 **`AGENTS.md`**（开工指令）与 **`docs/STATE.md`**（当前状态）。

```powershell
python tests/run_all.py              # 全部测试（退出码 0 = 通过）
python tests/run_all.py --list       # 看各层用例数
python tests/run_all.py --suite unit # 只跑某一层
python tools/check_footprint.py      # 足迹校验（41 个源文件 / 2 个功能）
python tools/gen_footprint.py        # 源码变动后刷新 docs/footprint.json

# 真实游戏样本（不入库）：
$env:TUDOU_RPGTOOL_SAMPLES = 'D:\gamess'
python tests/run_all.py
```

**加一个新功能只需要三步**（契约见 `docs/FEATURES.md`）：

1. 建 `features/<名字>/`：`__init__.py` + `manifest.py`（含 `MANIFEST` 与 `register(ctx)`）
2. 建 `ui/web/pages/<页面id>.js`（导出 `render(host, ctx)`）
3. 建 `tests/features/<名字>/test_manifest.py`

导航会自动出现 —— **不需要改 `app.py` / `ui/server.py` / `index.html`**。

## 六、目录结构

```text
├─ 启动.bat / run.py       # 双击启动入口（批处理只做转发，逻辑在 run.py）
├─ app.py                  # 唯一入口：装配 core/ui/features 并启动服务
├─ core/                   # 与界面无关的纯逻辑（不得 import ui / features）
│  ├─ engines.py           #   引擎识别 + 数据/存档目录发现
│  ├─ marshal/             #   Ruby Marshal（字节级保真）
│  ├─ formats/             #   MV/MZ 与 RGSS 的数据、存档读写
│  └─ safety/              #   原子写 / 备份还原 / 生成汉化版编排
├─ features/               # 一个目录 = 一个可插拔功能
│  ├─ translate/           #   文本翻译
│  └─ cheats/              #   存档修改
├─ ui/                     # 界面：HTTP 服务 + 无构建的单页前端
├─ tests/                  # unit / compat / features / integration / local
├─ tools/                  # 足迹校验与生成
├─ docs/                   # 状态、架构、决策、足迹（AGENTS.md 指明阅读顺序）
└─ runtime/                # 运行时数据（会话、日志；不入库）
```

## 七、常见问题

**Q：双击 `启动.bat` 没反应 / 闪一下就没了？**
A：说明没找到 Python 或自检没过。在命令行里跑一次，错误信息会留住：

```powershell
python app.py --check
```

**Q：提示端口被占用？**
A：`启动.bat --port 0` 会用随机空闲端口；或关掉占用该端口的程序。
若占用者是本工具的旧实例，`app.py` 会**主动回收**它（会先校验 `/api/health`）。

**Q：翻译了一大堆但游戏里没变？**
A：检查是不是选了「写副本」——那样汉化版在**新目录**里，原游戏不会变。
若确实要改原游戏，选「覆盖原游戏」，它会先备份。

**Q：改完存档游戏读不出来？**
A：在「备份列表」里点该次备份的「还原」。还原前工具还会为当前状态再备份一次。

**Q：能把改存档的"覆盖原存档"关掉吗？**
A：每次都要求二次确认，且确认不会记住 —— 这是有意的（防止误点）。

**Q：支持哪些游戏？**
A：MV / MZ / VX Ace / VX / XP。2000/2003 只识别不修改。
汉化版 / 破解版 / MTool 修改版游戏**已做容错**（加密 JSON 包装、非标准 marshal、
多流存档、额外字段都处理了），但"支持哪些变体"有明确记录，见 `docs/STATE.md`。
